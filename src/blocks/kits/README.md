# Как собрать страницу из секций

Сохрани копию своей папки проекта. Выбери тему и заменяй по одной секции. Переноси свои тексты и изображения в готовую разметку, затем открывай страницу и проверяй результат.

1. Оставь в `index.html` один `<head>` с кодировкой UTF-8, названием, метатегом viewport и строкой `<link rel="stylesheet" href="style.css">`.
2. В начале `style.css` вставь `shared/base.css`, затем `theme.css` выбранной темы. Ниже добавляй CSS нужных секций из папки `shared`. Если в проекте есть старые общие стили, проверь, что они не переопределяют фон, шрифт и размеры новой страницы.
3. В начало `<body>` вставь `header.html`. Оберни секции от первого экрана до последнего блока в `<main id="main">`. После `</main>` вставь `footer.html`. Проверь, что у страницы один заголовок `h1`.
4. Создай папку `img` рядом с `index.html`. Перенеси туда нужные картинки под именами из HTML. Если меняешь картинку, обнови путь и описание `alt`.
5. Для интерактива вставь нужный код в `script.js` и подключи его строкой `<script src="script.js" defer></script>` в `<head>`. Проверь меню, кнопки и ссылки на телефоне и компьютере.

| Тема | Порядок блоков внутри `main` |
| --- | --- |
| Киносфера | Первый экран, шаги, фильмы |
| Тиммейт | Первый экран, анкеты, отзывы |
| Куда сходить | Первый экран, фильтры, события |
| Хвост домой | Первый экран, питомцы, форма |
| Скинемся | Первый экран, шаги, пример сбора |
| Своя тема | Первый экран, карточки |

- Для сворачиваемого меню добавь `shared/burger.css` и `shared/burger.js`. Кнопка появится на телефоне после подключения скрипта.
- Для кнопки «О проекте» вставь `shared/modal.html` в конец `body`, добавь `shared/modal.css` и `shared/modal.js`. Замени текст внутри окна.
- Для афиши добавь `shared/filters.css` и `shared/filters.js`. Значения `data-kit-filter` у кнопок должны совпадать со значениями `data-kit-category` у карточек.
- Для формы волонтёров добавь `shared/form.css` и `shared/form.js`. Форма проверяет имя и электронную почту. Ввод остаётся в браузере.
- Если пропускаешь секцию или меняешь её `id`, обнови ссылки в шапке и на первом экране.

## Где лежат файлы

В каждой папке темы лежат её HTML-секции и `theme.css`. Для каждой HTML-секции используй одноимённый CSS из `shared`. В `manifest.json` перечислены блоки темы в порядке сборки. Поле `images` сопоставляет имена файлов в папке ученика `img` с путями к исходникам внутри `public`. Эти же пути можно использовать для скачивания картинок в библиотеке.

Для проверки локальной сборки из корня проекта запусти `node tools/check-site-kits.mjs`. Нужны Chrome и Playwright. Если Playwright установлен вне проекта, укажи путь к его `index.mjs` в `NAV_AUDIT_PLAYWRIGHT`. Собранные примеры появятся в `.astro/site-kits`.
