## Как вести пару

- Одна пара = одно занятие маршрута, 80 минут. Время на каждый шаг указано в его шапке. Суммы по занятиям — на странице [Маршрут](../route/).
- Начало шага (2–3 мин): прочитайте вслух цель, покажите пример из теории на проекторе.
- Разминку каждый делает сам, прямо на сайте. Зелёная плашка «Всё верно» = можно переходить к заданию «Делаем свой сайт».
- Подсказки открываются по очереди. Попросите команды открывать «Решение» только после двух подсказок.
- Раз в 20–30 минут обходите команды: пусть покажут чек-лист шага.

## Если команда отстаёт

- Минимальная цель — главная страница по макету. Шаги занятий 1–3 важнее, чем hover и мелкая сверка.
- Дайте готовый блок из раздела [Блоки](../blocks/) — лучше вставить и понять, чем застрять на час.
- Прогресс хранится в браузере конкретного компьютера. Если ученик пересел, отметки и черновики не переедут — это нормально, код проекта у него в папке.

## Как добавить или поменять шаг

Коротко (подробная инструкция — в `README.md` репозитория):

1. Скопируйте образец `templates/step.mdx` в папку занятия, например `src/content/docs/lesson-2/2-1-figma.mdx` (заглушки уже лежат там — их можно просто дописать).
2. Заполните верх файла между `---`: название, `minutes`, цель, ссылки, разминку, чек-лист, частые ошибки. Уберите строку `soon: true`.
3. Напишите текст под заголовками «Теория», «Делаем свой сайт» и подсказки.
4. Проверьте, что сайт собирается: локально `npm run build` или вкладка Actions на GitHub.

Время маршрута пересчитается само. Если сумма превысит 7 × 80 = 560 минут, при сборке появится предупреждение.
