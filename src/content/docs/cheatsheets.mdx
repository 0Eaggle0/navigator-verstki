## Скелет страницы

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Название сайта</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>…</header>
  <main>
    <section>…</section>
  </main>
  <footer>…</footer>
</body>
</html>
```

## Частые теги

| Тег | Для чего |
|---|---|
| `header`, `main`, `footer` | шапка, основное содержимое, подвал |
| `section` | смысловой блок с заголовком |
| `nav` | меню |
| `h1`–`h3` | заголовки: h1 один на страницу |
| `p` | абзац |
| `ul` + `li` | список (меню, пункты) |
| `a href="…"` | ссылка |
| `img src="…" alt="…"` | картинка, alt обязателен |
| `button` | кнопка, которая что-то делает на странице |
| `article` | карточка — законченный повторяющийся кусок |

## CSS: как устроено правило

```css
/* селектор { свойство: значение; } */
.card {
  padding: 16px;          /* внутренний отступ */
  margin-bottom: 24px;    /* внешний отступ снизу */
  background: #fff5ec;    /* фон */
  border-radius: 12px;    /* скругление углов */
}
```

Селекторы: `h1` — все h1, `.card` — все с классом card, `.card h3` — h3 внутри .card.

## Частые CSS-свойства

| Свойство | Пример | Что делает |
|---|---|---|
| `color` | `color: #1E1E1E;` | цвет текста |
| `background` | `background: #FFF8F0;` | фон |
| `font-family` | `font-family: 'Montserrat', sans-serif;` | шрифт |
| `font-size` / `font-weight` | `font-size: 18px; font-weight: 700;` | размер и жирность |
| `line-height` | `line-height: 1.5;` | высота строки |
| `text-align` | `text-align: center;` | выравнивание текста |
| `text-decoration` | `text-decoration: none;` | убрать подчёркивание |
| `width` / `max-width` | `max-width: 1200px;` | ширина, «не шире чем» |
| `padding` | `padding: 16px 24px;` | внутренний отступ |
| `margin` | `margin: 0 auto;` | внешний отступ, по центру |
| `border` / `border-radius` | `border: 1px solid #ddd; border-radius: 12px;` | рамка и скругление |
| `display` | `display: flex;` / `grid` / `none` | как ведёт себя блок |
| `gap` | `gap: 24px;` | промежутки во flex и grid |
| `object-fit` | `object-fit: cover;` | картинка заполняет рамку без искажений |
| `transition` | `transition: 0.2s;` | плавная смена стилей |

## Flexbox и Grid на одной схеме

Flexbox — **один ряд**, элементы идут друг за другом. Grid — **сетка** из колонок, элементы раскладываются по ячейкам.

<Preview
  html={`<p class="label">display: flex; justify-content: space-between; align-items: center; gap: 8px;</p>
<div class="flex"><div>1</div><div class="tall">2</div><div>3</div></div>
<p class="label">display: grid; grid-template-columns: repeat(3, 1fr); gap: 8px;</p>
<div class="grid"><div>1</div><div>2</div><div>3</div><div>4</div><div>5</div></div>`}
  css={`body { font-family: system-ui, sans-serif; }
.label { margin: 8px 0 4px; font: 12px/1.3 ui-monospace, monospace; color: #555; }
.flex { display: flex; justify-content: space-between; align-items: center; gap: 8px; height: 80px; padding: 8px; background: #EEF2FF; }
.grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 8px; padding: 8px; background: #FEF3C7; }
.flex div, .grid div { padding: 8px 16px; background: #fff; border-radius: 6px; text-align: center; }
.tall { padding-block: 24px !important; }`}
  height={260}
/>

| Нужно | Flexbox | Grid |
|---|---|---|
| Включить | `display: flex` | `display: grid` |
| Колонки | — | `grid-template-columns: repeat(3, 1fr)` |
| Вдоль ряда | `justify-content: space-between / center` | `justify-items` |
| Поперёк ряда | `align-items: center` | `align-items` |
| Промежутки | `gap: 16px` | `gap: 16px` |
| Перенос | `flex-wrap: wrap` | сам, с `repeat(auto-fill, minmax(240px, 1fr))` |
| Столбиком | `flex-direction: column` | `grid-template-columns: 1fr` |
| Растянуть элемент | `flex: 1` | `grid-column: span 2` |

## Медиазапрос

```css
/* обычные стили — для компьютера */
.cards { grid-template-columns: repeat(3, 1fr); }

/* всё, что ниже, — только для экранов уже 768px */
@media (max-width: 768px) {
  .cards { grid-template-columns: 1fr; }
}
```

## JavaScript: самое нужное

```js
// Найти элементы
const button = document.querySelector('.button');     // первый подходящий
const cards = document.querySelectorAll('.card');     // все подходящие (список)

// Реагировать на клик
button.addEventListener('click', function () {
  // что сделать
});

// Классы — меняем вид через CSS
menu.classList.add('open');
menu.classList.remove('open');
menu.classList.toggle('open');       // вернёт true, если класс добавился
menu.classList.contains('open');     // есть ли класс

// Текст и атрибуты
title.textContent = 'Новый заголовок';
button.setAttribute('aria-expanded', true);
card.dataset.type;                   // значение data-type="…"
card.hidden = true;                  // спрятать элемент

// Пройти по списку
cards.forEach(function (card) {
  console.log(card.dataset.type);
});

// Модальное окно на теге <dialog>
modal.showModal();
modal.close();

// Форма
form.addEventListener('submit', function (event) {
  event.preventDefault();            // не перезагружать страницу
  const name = form.elements.name.value.trim();
});

// localStorage — хранит только строки
localStorage.setItem('favorites', JSON.stringify(list));
const saved = JSON.parse(localStorage.getItem('favorites') || '[]');
```
