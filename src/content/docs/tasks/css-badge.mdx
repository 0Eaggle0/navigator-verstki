Маленькие метки — «Бесплатно», «Новое», «Хит» — делаются одним классом. Цвета берём из переменных.

<Warmup />

<Hint title="Подсказка 1">
`999px` — трюк: радиус больше высоты элемента делает края полностью круглыми.
</Hint>

<Hint title="Подсказка 2">
Переменная объявляется с двумя дефисами: `--accent: #16A34A;`, используется так: `var(--accent)`.
</Hint>

<Hint title="Решение">
```css
:root {
  --accent: #16A34A;
}

.badge {
  padding: 4px 12px;
  border-radius: 999px;
  background: var(--accent);
  color: #FFFFFF;
  font-size: 14px;
}
```
</Hint>
