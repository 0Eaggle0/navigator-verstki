Общие стили задают цвет, шрифт и ширину содержимого. Максимальная ширина позволяет блоку сжиматься на телефоне.

<Warmup />

<Hint title="Подсказка 1">
Переменную удобно объявить в `:root`. Для обращения к ней используется `var()`.
</Hint>

<Hint title="Подсказка 2">
Автоматические боковые отступы делят свободное место поровну.
</Hint>

<Hint title="Разбор разминки" afterPractice>
```css
:root { --accent: #265846; }
body { font-family: system-ui, sans-serif; }
h1 { color: var(--accent); }
.container { max-width: 600px; margin-inline: auto; }
```
</Hint>
