  task: "В поле CSS замени ___ на «600px». Затем нажми «Проверить»."
  html: |
    <main class="container">
      <h1>Клуб настольных игр</h1>
      <p>Встречаемся по выходным.</p>
    </main>
  css: |
    :root { --accent: #265846; }
    body { font-family: system-ui, sans-serif; }
    h1 { color: var(--accent); }
    .container { max-width: ___; margin-inline: auto; }
  answer:
    field: css
    missing: "600px"
  normal:
    task: Ограничь ширину .container до 600 пикселей. На телефоне контейнер должен сжиматься.
    explanation: max-width задаёт верхний предел ширины и позволяет блоку стать уже. Обычное width с числом в px задаёт фиксированную ширину.
    example: '.article { max-width: 480px; }'
    replacement: "1200px"
  hard:
    task: 'Объяви переменную --accent со значением #265846 и используй её для цвета заголовка. Задай странице шрифт system-ui с запасным sans-serif. Ограничь ширину контейнера 600 px и выровняй его по центру автоматическими боковыми отступами.'
    html: |
      <main class="container">
        <h1>Клуб настольных игр</h1>
        <p>Встречаемся по выходным.</p>
      </main>
    css: ''
  checks:
    - js: |
        const root = doc.documentElement;
        const title = doc.querySelector('h1');
        if (getComputedStyle(title).color !== 'rgb(38, 88, 70)') return false;
        root.style.setProperty('--accent', '#123456', 'important');
        return getComputedStyle(title).color === 'rgb(18, 52, 86)';
      fail: "Цвет заголовка должен меняться вместе с переменной акцента."
    - js: "return getComputedStyle(doc.body).fontFamily.split(',').map(value => value.trim()).join(',') === 'system-ui,sans-serif'"
      fail: "Задай системный шрифт с запасным sans-serif."
    - js: |
        const box = doc.querySelector('.container').getBoundingClientRect();
        const body = doc.body.getBoundingClientRect();
        return Math.abs(box.width - Math.min(600, body.width)) < 2 &&
          Math.abs((box.left + box.right - body.left - body.right) / 2) < 2;
      widths: [375, 768]
