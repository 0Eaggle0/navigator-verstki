Нативный элемент `progress` показывает долю выполненного. Например, `<progress value="3" max="5" aria-label="Прочитано глав"></progress>` показывает три главы из пяти.

<Warmup />

<Hint title="Подсказка 1">
Для атрибутов полоски нужны числа без пробелов и знака валюты.
</Hint>

<Hint title="Подсказка 2">
Значение `aria-labelledby` указывает на идентификатор уже существующего заголовка.
</Hint>

<Hint title="Разбор разминки" afterPractice>
```html
<article class="goal">
  <h2 id="goal-title">Поездка за город</h2>
  <p>Собрано 8 400 ₽ из 12 000 ₽</p>
  <progress value="8400" max="12000" aria-labelledby="goal-title">70%</progress>
</article>
```
</Hint>
