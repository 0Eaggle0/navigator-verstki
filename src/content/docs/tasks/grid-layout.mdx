Раскладка «широкая колонка + узкая» — статья и боковая панель, карточка события и блок покупки.

<Warmup />

<Hint title="Подсказка 1">
`fr` — доля свободного места. `2fr 1fr` — всего 3 доли, левой достаются 2.
</Hint>

<Hint title="Подсказка 2">
Промежуток между колонками — `gap`, как во флексе.
</Hint>

<Hint title="Решение">
```css
.layout {
  display: grid;
  grid-template-columns: 2fr 1fr;
  gap: 16px;
}
```
</Hint>
