Поставить элемент ровно в центр блока — классическая задача, которую Flexbox решает в три строки.

<Warmup />

<Hint title="Подсказка 1">
По горизонтали центрирует `justify-content`, по вертикали — `align-items`.
</Hint>

<Hint title="Подсказка 2">
Оба свойства пишутся контейнеру `.box`, а не кружку.
</Hint>

<Hint title="Решение">
```css
.box {
  display: flex;
  justify-content: center;
  align-items: center;
}
```
</Hint>
