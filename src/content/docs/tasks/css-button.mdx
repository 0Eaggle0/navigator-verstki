Большинство кнопок на сайтах — это ссылки, оформленные как кнопка.

<Warmup />

<Hint title="Подсказка 1">
Порядок в `padding: 12px 24px`: сначала сверху-снизу, потом слева-справа.
</Hint>

<Hint title="Подсказка 2">
Без `display: inline-block` вертикальный padding у ссылки работает странно.
</Hint>

<Hint title="Решение">
```css
.button {
  display: inline-block;
  padding: 12px 24px;
  background: #4F46E5;
  color: #FFFFFF;
  text-decoration: none;
  border-radius: 8px;
}
```
</Hint>
