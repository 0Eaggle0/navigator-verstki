Перед отправкой форму проверяют: заполнены ли поля и правильно ли. Ошибку показывают текстом рядом.

<Warmup />

<Hint title="Подсказка 1">
Пробелы по краям имени не считаются содержимым. Обработчик должен отличать пустую строку от имени.
</Hint>

<Hint title="Подсказка 2">
Раздели действия для ошибки и успеха. При ошибке оставь поля, чтобы имя можно было исправить.
</Hint>

<Hint title="Разбор разминки" afterPractice>
```js
const form = document.querySelector('.form');

form.addEventListener('submit', function (event) {
  event.preventDefault();
  const name = form.elements.name.value.trim();
  const error = form.querySelector('.error');

  if (name === '') {
    error.textContent = 'Напиши своё имя';
    return;
  }
  error.textContent = '';
  form.innerHTML = '<p>Спасибо!</p>';
});
```
</Hint>
