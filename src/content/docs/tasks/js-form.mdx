Перед отправкой форму проверяют: заполнены ли поля и правильно ли. Ошибку показывают текстом рядом.

<Warmup />

<Hint title="Подсказка 1">
`value.trim()` убирает пробелы по краям — поле из одних пробелов тоже считается пустым.
</Hint>

<Hint title="Подсказка 2">
Заменить содержимое формы: `form.innerHTML = '<p>Спасибо!</p>';`.
</Hint>

<Hint title="Решение">
```js
const form = document.querySelector('.form');

form.addEventListener('submit', function (event) {
  event.preventDefault();
  const name = form.elements.name.value.trim();
  const error = form.querySelector('.error');

  if (name === '') {
    error.textContent = 'Напиши своё имя';
    return;
  }
  error.textContent = '';
  form.innerHTML = '<p>Спасибо!</p>';
});
```
</Hint>
