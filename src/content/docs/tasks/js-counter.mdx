Переменная, событие и запись в DOM — всё, что нужно для счётчика «лайков» или «иду».

<Warmup />

<Hint title="Подсказка 1">
Увеличить переменную: `count = count + 1;` или короче `count++;`.
</Hint>

<Hint title="Подсказка 2">
Записать число на страницу: `document.querySelector('.count').textContent = count;`.
</Hint>

<Hint title="Решение">
```js
let count = 0;
const countEl = document.querySelector('.count');

document.querySelector('.plus').addEventListener('click', function () {
  count = count + 1;
  countEl.textContent = count;
});
```
</Hint>
