Меню сайта почти всегда — список ссылок. Так его понимают поисковики и программы экранного доступа.

<Warmup />

<Hint title="Подсказка 1">
Структура: `nav` → `ul` → три `li` → в каждом `a`.
</Hint>

<Hint title="Подсказка 2">
Пока страниц нет, пишите `href="#"`.
</Hint>

<Hint title="Решение">
```html
<nav>
  <ul>
    <li><a href="#">Главная</a></li>
    <li><a href="#">Каталог</a></li>
    <li><a href="#">Контакты</a></li>
  </ul>
</nav>
```
</Hint>
