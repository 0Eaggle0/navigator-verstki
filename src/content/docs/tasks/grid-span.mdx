В сетке карточек первую часто делают крупнее — например, главное событие недели.

<Warmup />

<Hint title="Подсказка 1">
Свойство пишется самой карточке, а не сетке.
</Hint>

<Hint title="Подсказка 2">
`span 2` значит «занять две колонки». Остальные карточки сетка расставит сама.
</Hint>

<Hint title="Решение">
```css
.card--big {
  grid-column: span 2;
}
```
</Hint>
