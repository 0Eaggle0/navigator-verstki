Самая частая причина прокрутки вбок на телефоне — картинка шире экрана.

<Warmup />

<Hint title="Подсказка 1">
`max-width: 100%` — «не шире родителя». На широком экране картинка останется 600 px.
</Hint>

<Hint title="Подсказка 2">
Атрибут `height="400"` в HTML фиксирует высоту. `height: auto` в CSS пересчитает её по ширине.
</Hint>

<Hint title="Решение">
```css
img {
  max-width: 100%;
  height: auto;
}
```
</Hint>
