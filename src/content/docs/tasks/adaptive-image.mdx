    task: Сделай так, чтобы картинка не становилась шире своего контейнера.
    explanation: max-width ограничивает ширину. Значение 100% означает всю ширину контейнера, 50% — половину.
    example: '.logo { max-width: 50%; }'
    replacement: "150%"

    task: 'Превью шириной 375 px. Картинка шириной 600 px ломает страницу. Сделай так, чтобы она не выходила за экран (max-width: 100%) и сохраняла пропорции (height: auto).'
