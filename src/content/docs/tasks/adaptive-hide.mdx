На телефоне не всё нужно показывать. Длинный слоган или декоративную картинку часто прячут.

<Warmup />

<Hint title="Подсказка 1">
Оба правила — внутри одного медиазапроса.
</Hint>

<Hint title="Подсказка 2">
Без медиазапроса `.desktop-only` пропадёт и на компьютере — так нельзя.
</Hint>

<Hint title="Решение">
```css
@media (max-width: 768px) {
  .desktop-only {
    display: none;
  }

  .cards {
    grid-template-columns: 1fr;
  }
}
```
</Hint>
