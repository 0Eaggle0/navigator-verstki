Внизу сайтов часто строка: копирайт слева, соцсети справа. На узком экране — переносится.

<Warmup />

<Hint title="Подсказка 1">
Здесь два флекса: у `.bottom` (копирайт и блок соцсетей) и у `.socials` (сами ссылки).
</Hint>

<Hint title="Подсказка 2">
У `p` есть стандартный margin — если строка получилась высокой, добавьте `.bottom p { margin: 0; }`.
</Hint>

<Hint title="Решение">
```css
.bottom {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
  align-items: center;
}

.socials {
  display: flex;
  gap: 12px;
}
```
</Hint>
