## Теория

<Npc>

**GitHub** — сайт, где хранят код, а **GitHub Pages** — его бесплатный хостинг. Кладёте файлы сайта в репозиторий (папку на GitHub), включаете Pages — и через минуту сайт открывается по адресу `https://логин.github.io/название-репозитория/`. Git и командная строка для этого не нужны: всё делается в браузере.

Главная ловушка — **пути к файлам**. На вашем компьютере работает и `C:\Users\Аня\Desktop\site\img\cat.jpg`, но в интернете такого диска нет. Путь `/img/cat.jpg` со слешем в начале ведёт в корень `логин.github.io`, а не в ваш сайт. Правильно — **относительные** пути от `index.html`: `img/cat.jpg`, `style.css`, `about.html`.

Вторая ловушка — **регистр букв**. Windows не различает `Cat.JPG` и `cat.jpg`, а GitHub различает. Называйте файлы латиницей, маленькими буквами, без пробелов: `hero-dog.jpg`.

Главный файл обязательно называется `index.html` и лежит в корне репозитория — его GitHub Pages открывает по адресу сайта.

</Npc>

## Делаем свой сайт

Публикует один человек в команде, остальные смотрят.

1. Зарегистрируйтесь на [github.com](https://github.com) (нужна почта).
2. Нажмите **+** → **New repository**. Название латиницей, например `hvost-domoy`. Отметьте **Public** → **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**. Перетащите в окно **содержимое** папки проекта: `index.html`, `style.css`, `script.js`, папку `img`. Нажмите **Commit changes**.
4. Откройте **Settings** → **Pages**. В **Source** выберите **Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты вверху страницы Pages появится ссылка на сайт. Откройте её с компьютера и с телефона.
6. Нашли ошибку? Исправьте файл на компьютере и загрузите его снова через **Add file** → **Upload files** — сайт обновится сам.

<Hint title="Подсказка 1">
Перед загрузкой откройте `index.html` в VS Code и поищите (Ctrl+F) `C:` и `src="/` — всё найденное нужно исправить на относительные пути.
</Hint>

<Hint title="Подсказка 2">
Если сайт открылся, а картинки нет — откройте на сайте DevTools → Console. Ошибка 404 покажет, какой файл браузер искал и не нашёл. Сравните имя с тем, что лежит в репозитории, до буквы.
</Hint>

<Hint title="Решение">
```html
<img src="img/barsik.svg" alt="Кот Барсик" width="150">
<img src="img/sharik.svg" alt="Пёс Шарик" width="150">

```
