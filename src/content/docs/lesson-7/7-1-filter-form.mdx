## Теория

<Npc>

У любого элемента можно хранить свои данные в атрибутах `data-…`: `<article data-type="cat">`. В JS они доступны через `dataset`: `card.dataset.type` вернёт `"cat"`. Так мы помечаем карточки для фильтра.

Много элементов находит `document.querySelectorAll` — он возвращает список. Пройти по списку помогает `forEach`: «для каждой карточки сделай…».

```js
cards.forEach(function (card) {
  card.hidden = card.dataset.type !== 'cat';
});
```

Свойство `hidden = true` прячет элемент, `false` — показывает. Выражение `card.dataset.type !== 'cat'` даёт `true` для всех «не кошек» — их и прячем.

Для формы главное событие — `submit`. В обработчике сначала `event.preventDefault()` (не перезагружать страницу), потом проверяем поля: `input.value.trim() === ''` — поле пустое. Ошибку показываем текстом рядом с полем.

<button type="button" data-filter="cat">Кошки</button>
<p class="card" data-type="cat">🐱 Барсик</p>
<p class="card" data-type="dog">🐶 Шарик</p>`}
  js={`const cards = document.querySelectorAll('.card');
document.querySelectorAll('[data-filter]').forEach(function (button) {
  button.addEventListener('click', function () {
    const filter = button.dataset.filter;
    cards.forEach(function (card) {
      card.hidden = filter !== 'all' && card.dataset.type !== filter;
    });
  });
});`}

<Hint title="Решение">
Фильтр:

```js
const buttons = document.querySelectorAll('[data-filter]');
const cards = document.querySelectorAll('.card');

buttons.forEach(function (button) {
  button.addEventListener('click', function () {
    const filter = button.dataset.filter;
    cards.forEach(function (card) {
      card.hidden = filter !== 'all' && card.dataset.type !== filter;
    });
    buttons.forEach((b) => b.classList.remove('active'));
    button.classList.add('active');
  });
});
```

Форма (подходит к блоку «Форма»: поля `name`, `phone`, `agree` и `<p class="error">`):

```js
const form = document.querySelector('.form');
const error = form.querySelector('.error');

form.addEventListener('submit', function (event) {
  event.preventDefault();
  const name = form.elements.name.value.trim();
  // оставляем в телефоне только цифры
  const phone = form.elements.phone.value.replace(/\D/g, '');

  if (name === '') {
    error.textContent = 'Напиши своё имя';
    return;
  }
  if (phone.length < 10) {
    error.textContent = 'В телефоне должно быть хотя бы 10 цифр';
    return;
  }
  if (!form.elements.agree.checked) {
    error.textContent = 'Поставь галочку согласия';
    return;
  }
  form.innerHTML = '<p>Спасибо, мы позвоним!</p>';
});
```
