## Теория

<Npc>

Всё, что меняет JavaScript на странице, пропадает после перезагрузки. **localStorage** — маленькое хранилище в браузере, где данные живут, пока пользователь сам их не удалит. Прогресс в этом навигаторе хранится именно так.

Хранилище работает как словарь «ключ → строка»:

```js
localStorage.setItem('theme', 'dark');   // сохранить
localStorage.getItem('theme');           // прочитать → 'dark' (или null, если нет)
localStorage.removeItem('theme');        // удалить
```

Хранятся только **строки**. Список или объект сначала превращаем в строку `JSON.stringify(list)`, а при чтении обратно — `JSON.parse(text)`. Запись `|| '[]'` подставляет пустой список, если ключа ещё нет.

В некоторых браузерах (приватный режим, запрет cookies) localStorage недоступен и бросает ошибку. Чтобы сайт не ломался, чтение и запись оборачивают в `try { … } catch { … }`.

## Делаем свой сайт

<ForCase>
Сохраните что-то, что пользователь выбрал сам: избранное, тему, заполненное поле формы. Выберите кейс на главной странице навигатора — здесь появится задание под ваш сайт.

<ForCase id="where">
**Избранные события.** Кнопка ♥ на карточке события добавляет его в избранное, выбор сохраняется. Можно добавить кнопку фильтра «Избранное» из шага 7.1.
</ForCase>

<ForCase id="watch">
**Список «Хочу посмотреть».** Кнопка на карточке фильма сохраняет его id. Над карточками — счётчик «В списке: 3 фильма», который обновляется после каждого клика.
</ForCase>

<ForCase id="teammate">
**Сохранённые анкеты.** Кнопка «Сохранить» на анкете запоминает её, сохранённые анкеты подсвечены рамкой.
</ForCase>

<ForCase id="tail">
**Понравившиеся питомцы.** Кнопка ♥ на карточке питомца, выбор сохраняется. А ещё можно сохранять имя и телефон из формы волонтёра, чтобы при повторном визите их не вводить.
</ForCase>

<ForCase id="split">
**Черновик сбора.** Поля формы «Создать сбор» сохраняются при каждом вводе (событие `input`) и восстанавливаются при открытии окна. После успешного создания черновик удаляется.
</ForCase>

1. Решите, что сохранять и под каким ключом.
2. При загрузке страницы прочитайте данные и восстановите вид.
3. При изменении — сохраните.
4. Проверьте: выберите что-нибудь, обновите страницу (F5) — выбор на месте. Данные видно в DevTools → Application → Local Storage.

<Hint title="Подсказка 1">
Заведите две маленькие функции и пользуйтесь только ими: `load()` читает список (в `try`), `save(list)` сохраняет (в `try`). Так проще не забыть JSON.
</Hint>

<Hint title="Подсказка 2">
Добавить в список: `list.push(id)`. Убрать: `list = list.filter((x) => x !== id)`. Есть ли в списке: `list.includes(id)`.
</Hint>

<Hint title="Решение">
```js
function load() {
  try {
    return JSON.parse(localStorage.getItem('favorites') || '[]');
  } catch {
    return [];
  }
}

function save(list) {
  try {
    localStorage.setItem('favorites', JSON.stringify(list));
  } catch {}
}

document.querySelectorAll('.card').forEach(function (card) {
  const button = card.querySelector('.fav');
  const id = card.dataset.id;

  button.classList.toggle('active', load().includes(id));

  button.addEventListener('click', function () {
    let list = load();
    if (list.includes(id)) {
      list = list.filter((x) => x !== id);
    } else {
      list.push(id);
    }
    save(list);
    button.classList.toggle('active', list.includes(id));
  });
});
```
