## Теория

<Npc>

Аттестация проверяет не красоту, а качество: насколько страница соответствует макету и базовым правилам вёрстки. Хорошая новость — всё это вы уже делали по шагам. Осталось пройтись одним списком и ничего не забыть.

Проверяйте глазами **и** инструментами:
- **DevTools в режиме телефона** (375 px) — нет прокрутки вбок, всё читается;
- **W3C Validator** (ссылка ниже) — вставьте адрес сайта, он покажет ошибки HTML: незакрытые теги, дубли `id`, картинки без `alt`;
- **Консоль** (F12) — нет красных ошибок JavaScript и 404.

Делите проверку между участниками: один смотрит телефон, второй валидатор, третий сверяет с макетом, четвёртый проверяет ссылки и кнопки.

</Npc>

## Делаем свой сайт: чек-лист сдачи

**Минимум — главная страница:**
- [ ] Семантика: `header`, `nav`, `main`, `section`, `footer`, один `h1`, заголовки по уровням
- [ ] Шрифты и цвета как в макете, цвета в CSS-переменных
- [ ] На 1280 px страница похожа на макет
- [ ] На 375 px нет горизонтальной прокрутки, текст читается
- [ ] У всех картинок осмысленный `alt`
- [ ] У кнопок и ссылок есть `:hover`, все ссылки куда-то ведут
- [ ] Сайт открывается по ссылке GitHub Pages

**Идеал — интерактив:**
- [ ] Бургер-меню на телефоне
- [ ] Модальное окно по главной кнопке
- [ ] Фильтр карточек или форма с проверкой
- [ ] Выбор пользователя сохраняется в localStorage
- [ ] В консоли нет ошибок

<Hint title="Подсказка 1">
Быстрая проверка `alt`: в консоли сайта выполните `document.querySelectorAll('img:not([alt])')` — покажет картинки без описания.
</Hint>

<Hint title="Подсказка 2">
Проверка лишних `h1`: `document.querySelectorAll('h1').length` в консоли должно дать `1`.
</Hint>

<Hint title="Решение">
```html
<header class="header">
  <h1>КУДА_СХОДИТЬ</h1>
</header>
<main>
  <h2>Афиша на выходные</h2>
  <img src="img/murka.svg" width="150" alt="Серая кошка Мурка">
  <p><a href="#events">Все события</a></p>
</main>
```
