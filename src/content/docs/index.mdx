## Как тут всё устроено

1. **Маршрут** — 4 занятия по 80 минут. Идите по шагам сверху вниз.
2. **Шаг** — цель и время, мини-теория, разминка в песочнице, задание для вашего сайта, подсказки.
3. **Застряли?** Внизу каждого шага есть кнопка «Я застрял» с частыми ошибками.
4. **Прогресс** сохраняется в этом браузере: отмеченные шаги, чек-листы, код разминок.
