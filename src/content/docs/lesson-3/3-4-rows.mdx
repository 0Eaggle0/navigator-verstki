## Теория

На странице много маленьких рядов: две кнопки рядом, иконки соцсетей, «три шага», преимущества. Все они делаются одним приёмом: `display: flex` + `gap`.

Если элементов много, на узком экране они не поместятся. `flex-wrap: wrap` разрешает перенос: лишние элементы уедут на следующую строку, а не сожмутся в кашу. Это пригодится в занятии 5, когда будем делать версию для телефона.

Внутри элемента (иконка сверху, подпись снизу) флекс тоже работает — только развёрнутый: `flex-direction: column`. Тогда `align-items: center` ставит всё по центру по горизонтали.

<Hint title="Подсказка 1">
Две кнопки рядом: оберните их в `<div class="buttons">` и дайте ему `display: flex; gap: 16px;`.
</Hint>

<Hint title="Подсказка 2">
Иконки соцсетей — это ссылки с картинками внутри. Картинкам задайте одинаковую высоту: `height: 32px`.
</Hint>

<Hint title="Решение">
```css
.features {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.feature {
  display: flex;
  flex-direction: column;
  align-items: center;
  text-align: center;
}
```
</Hint>
