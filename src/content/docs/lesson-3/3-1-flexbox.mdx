## Теория

<Npc>

Обычные блоки встают друг под другом. **Flexbox** — способ поставить их в ряд и выровнять. Включается одной строкой у **родителя**: `display: flex`. Все его прямые дети становятся флекс-элементами и выстраиваются в строку.

У ряда две оси. **Главная** идёт слева направо, по ней выравнивает `justify-content`: `flex-start` — прижать влево, `center` — по центру, `space-between` — разнести по краям. **Поперечная** идёт сверху вниз, по ней выравнивает `align-items`: `center` — по центру по вертикали.

Расстояние между элементами задаёт `gap: 16px` — это проще, чем margin у каждого. Если элементам тесно, `flex-wrap: wrap` разрешает перенос на новую строку. А `flex-direction: column` разворачивает ряд в столбик.

Лучший способ запомнить — поиграть 10 минут во **Flexbox Froggy** (ссылка ниже): там лягушек расставляют этими же свойствами.

<Hint title="Подсказка 1">
Запомните правило: «flex — родителю, выравнивание — родителю». Детям обычно ничего писать не нужно.
</Hint>

<Hint title="Подсказка 2">
В Chrome DevTools рядом с элементом, у которого `display: flex`, есть значок **flex**. Нажмите на него — на странице подсветится ряд и промежутки.
</Hint>

<Hint title="Решение">
```css
.row {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```
