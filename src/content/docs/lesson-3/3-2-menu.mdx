## Теория

<Npc>

Шапка почти всегда устроена одинаково: слева логотип, посередине или справа меню, с краю кнопка. Это три ребёнка у `<header>` — и одна строка `display: flex` ставит их в ряд.

`justify-content: space-between` разносит детей по краям и делит свободное место между ними поровну. `align-items: center` выравнивает по вертикали: логотип-картинка и текст меню разной высоты встают на одну линию.

Пункты меню — это внуки шапки: они лежат внутри `ul`. Флекс шапки на них не действует, поэтому списку нужен свой `display: flex`. Промежуток между пунктами задаём через `gap`, а точки списка убираем `list-style: none`.

Такая «матрёшка» из флексов — нормальная практика: у каждого ряда свой flex-контейнер.

## Делаем свой сайт

1. Содержимое шапки лежит в `.container` (шаг 2.3). Поэтому flex ставим контейнеру внутри шапки: `.header .container`. Именно его дети — логотип, `nav` и кнопка.
2. Задайте ему `display: flex`, `justify-content: space-between`, `align-items: center`.
3. Списку меню `ul.menu` — `display: flex` и `gap` из макета, уберите точки и отступы.
4. Сверьте с макетом расстояния между пунктами меню.

<BlockLinks />

<Hint title="Подсказка 1">
Нарисуйте на листке, что лежит в чём: `header` → `.container` → (`logo`, `nav` → `ul` → `li`, `button`). Flex нужен каждому, чьи дети должны стоять в ряд: это `.container` в шапке и `ul`.
</Hint>

<Hint title="Подсказка 2">
Если в макете кнопки в шапке нет и меню должно быть справа, `space-between` на двух элементах так и сработает: логотип слева, меню справа.
</Hint>

<Hint title="Решение">
```css
.header .container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 24px;
}

.menu {
  display: flex;
  gap: 24px;
  margin: 0;
  padding: 0;
  list-style: none;
}
```
</Hint>
