## Теория

«Текст слева — картинка справа» — самый частый первый экран. Это снова Flexbox: у секции два ребёнка — блок с текстом и картинка. `display: flex` ставит их в ряд, `align-items: center` выравнивает по вертикали, `gap` задаёт промежуток.

Кто сколько места займёт, решает свойство детей `flex`. `flex: 1` у обоих — поделить ширину поровну. `flex: 2` и `flex: 1` — две трети и одна треть. Это удобнее, чем считать проценты.

Картинке обязательно `max-width: 100%`: без этого большая фотография из макета вылезет за край. В стартовом сбросе это уже есть для всех `img`.

Текст, заголовок и кнопку внутри колонки трогать не нужно: они стоят друг под другом как обычно. Флекс действует только на прямых детей секции.

## Делаем свой сайт

<ForCase>
Выберите кейс на главной странице навигатора — здесь появится подсказка про первый экран вашего сайта.

<ForCase id="watch">
Главная кнопка — «Создать комнату». Рядом можно поставить вторую, контурную: «Войти по ссылке». Две кнопки ставьте в ряд через flex (шаг 3.4).

<ForCase id="teammate">
Главная кнопка — «Найти команду». Справа часто коллаж из аватаров — это одна картинка, экспортируйте её целиком.
</ForCase>

<ForCase id="where">
Под заголовком часто стоит строка поиска или выбор даты — пока просто сверстайте её как поле `input` без JS.
</ForCase>

<ForCase id="tail">
Главная кнопка — «Пройти тест». Фото питомца справа сделайте с `border-radius`, как в макете.
</ForCase>

<ForCase id="split">
Главная кнопка — «Создать сбор». Справа часто пример карточки сбора с прогрессом — можно сверстать его как картинку, а настоящий сделать позже.
</ForCase>

1. Проверьте HTML первого экрана: внутри секции (или её `.container`) ровно два блока — текст и картинка.
2. Поставьте их в ряд через flex, выровняйте, задайте промежуток из макета.
3. Задайте колонкам ширину через `flex`, чтобы пропорции совпали с макетом.
4. Оформите заголовок, текст и кнопку по паспорту стиля: размеры, цвета, отступы.

<Hint title="Подсказка 1">
Если секция внутри себя имеет `.container`, флекс ставится контейнеру: `.hero .container { display: flex; }`. Ставить его самой секции бесполезно — у неё один ребёнок.
</Hint>

<Hint title="Подсказка 2">
Колонка с текстом не сжимается и ломает ряд? Добавьте колонкам `min-width: 0` — это разрешает им становиться уже своего содержимого.
</Hint>

<Hint title="Решение">
```css
.hero .container {
  display: flex;
  align-items: center;
  gap: 32px;
}

.hero__text,
.hero__img {
  flex: 1;
  min-width: 0;
}

.hero h1 {
  margin-bottom: 16px;
  font-size: 48px;
}
```
</Hint>
