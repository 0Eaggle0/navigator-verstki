## Теория

<Npc>

Скелет готов — теперь наполняем его. Почти всё на главной странице собирается из пяти тегов:
- `<h1>`–`<h3>` — заголовки;
- `<p>` — абзац текста;
- `<img src="img/dog.jpg" alt="Пёс Шарик">` — картинка. В `src` путь к файлу, в `alt` — описание словами;
- `<a href="#pets">` — ссылка: на другую страницу или к секции с `id="pets"`;
- `<button>` — кнопка, которая что-то делает на этой же странице.

`alt` обязателен. Его зачитывают программы для незрячих, и его видно, если картинка не загрузилась. Пишите, что изображено: «Рыжий кот на подоконнике», а не «картинка1».

Списки — меню, пункты, преимущества — оформляйте через `<ul>` и `<li>`. Карточку удобно обернуть в `<article class="card">`: это законченный кусочек, который повторяется.

Картинки из Figma выгружаются через панель **Export**. Подробно разберём это в шаге 2.1. Если времени мало, сейчас просто поставьте `img` с будущим именем файла (латиницей без пробелов: `img/hero-dog.jpg`) и `alt`. Сам файл положите в `img` позже.

## Делаем свой сайт

<ForCase>
Выберите кейс на главной странице навигатора — здесь появится подсказка, из чего состоит карточка вашего сайта.
</ForCase>

<ForCase id="watch">
Карточка фильма: `img` постера с `alt` = название фильма, `h3` с названием, `p` с годом и жанром, рейтинг, кнопка «Хочу посмотреть».
</ForCase>

<ForCase id="teammate">
Карточка анкеты: `img` аватара с `alt` «Аватар Ани», `h3` с ником, список навыков `ul`, рейтинг, кнопка «Написать».
</ForCase>

<ForCase id="where">
Карточка события: `img` афиши, `h3` с названием, `p` с датой и местом, цена («Бесплатно» или «300 ₽»), кнопка «Иду».
</ForCase>

<ForCase id="tail">
Карточка питомца: `img` фото с `alt` «Рыжий кот Барсик», `h3` с кличкой, `p` с возрастом и характером, кнопка «Познакомиться».
</ForCase>

<ForCase id="split">
Пример сбора: `h3` с названием («Подарок Лене»), `p` «Собрано 3 200 из 5 000 ₽», полоска прогресса `<progress value="3200" max="5000">`, список участников.
</ForCase>

1. В каждую `section` перенесите контент по макету: заголовки, тексты, картинки, ссылки, кнопки. Картинки, которых ещё нет в `img`, — с будущим именем файла.
2. Меню в шапке сделайте списком ссылок: `<ul class="menu">` → `li` → `a`.
3. Кнопкам-ссылкам дайте класс `button`: `<a class="button" href="#">`. Оформим их все разом в занятии 2.
4. Сверстайте одну карточку до конца, проверьте её — и только потом копируйте для остальных.

Работаете вчетвером? Каждый участник пишет свою секцию в отдельном файле по шаблону:
<a href="../../starter/section.html" download>section.html</a> и
<a href="../../starter/section.css" download>section.css</a>.
Положите их в папку проекта рядом с `style.css`: шаблон подключает общие стили, поэтому секция выглядит так же, как на общей странице. Как потом собрать всё в один `index.html`, написано в шапке шаблона.

Страница пока будет выглядеть «голой», без оформления. Это нормально: стили — на следующем занятии.

<Hint title="Подсказка 1">
Идите по макету сверху вниз, секция за секцией. Тексты копируйте прямо из Figma, чтобы не было опечаток. Картинки, которых ещё нет, можно временно пропустить — оставьте комментарий `<!-- картинка hero -->`.
</Hint>

<Hint title="Подсказка 2">
Проверяйте пути к картинкам. Если страница лежит в папке проекта, а картинка в `img`, путь будет `img/имя.jpg` — без слеша в начале. Откройте консоль браузера (F12): ошибки 404 покажут, какой файл не нашёлся.
</Hint>
