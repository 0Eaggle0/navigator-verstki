## Теория

<Npc>

Можно сверстать страницу из одних `<div>` — браузер покажет её так же. Но тогда ни человек, ни программа не поймёт, где шапка, а где подвал. Поэтому для крупных частей есть **семантические** (смысловые) теги.

Главные теги скелета:
- `<header>` — шапка: логотип и меню. Меню кладём в `<nav>`.
- `<main>` — основное содержимое. Он на странице один.
- `<section>` — смысловой блок внутри `main`: первый экран, карточки, «о нас». У секции обычно есть заголовок.
- `<footer>` — подвал: контакты, соцсети.

Заголовки идут по уровням. `<h1>` — один на страницу, главный. У секций — `<h2>`, внутри них, например у карточек, — `<h3>`. Уровни не выбирают по размеру шрифта: размер потом зададим в CSS.

Каждой секции дай класс из списка, который вы составили в шаге 1.1: `<section class="pets">`. По классам будем писать стили.

## Делаем свой сайт

1. Откройте `index.html` своего проекта.
2. Внутри `<body>` соберите скелет: `header` → `main` → `footer`.
3. В `main` сделайте по одной `section` с классом на каждый крупный блок из вашего списка (шаг 1.1). В каждую секцию пока поставьте только заголовок.
4. Сохраните и проверьте в браузере: заголовки идут в том же порядке, что на макете.

Контент (тексты, картинки, кнопки) переносим в следующем шаге — сейчас только каркас.

<Hint title="Подсказка 1">
Пишите сначала пару тегов, потом содержимое: `<section class="pets"></section>`, и уже затем курсор внутрь. Так не потеряете закрывающий тег. В VS Code можно набрать `section.pets` и нажать Tab.
</Hint>

<Hint title="Подсказка 2">
Проверьте вложенность: `header`, `main` и `footer` лежат прямо в `body` рядом друг с другом. Все `section` — внутри `main`. Удобно временно добавить в `style.css` строку `section { outline: 2px dashed red; }` — будут видны границы секций.
</Hint>
