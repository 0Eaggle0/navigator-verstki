### Как читать код

Страница пишется на **HTML**. Он состоит из **тегов** — слов в угловых скобках. У большинства тегов есть пара: открывающий `<p>` и закрывающий `</p>` (со слешем). Всё, что между ними, — содержимое тега:

```html
<p>Привет!</p>
```

Теги вкладываются друг в друга, как коробки: `<div><p>Привет!</p></div>`. Закрывать их нужно в обратном порядке — сначала внутренний, потом внешний.

В открывающем теге бывают **атрибуты** — дополнительные настройки в виде `имя="значение"`. Самый частый — `class`, имя элемента для стилей: `<div class="header">`. Один класс можно дать многим элементам.

Оформление пишется на **CSS** правилами. Правило читается так: «найди элементы (**селектор**) и задай им **свойство** со **значением**». Селектор класса начинается с точки:

```css
.header {
  color: tomato;
  padding: 16px;
}
```

Каждая строка внутри фигурных скобок — пара `свойство: значение;`. Двоеточие и точка с запятой обязательны.

### Макет — это блоки

Любой сайт — это стопка прямоугольников. Сначала крупные: шапка, первый экран, секции, подвал. Внутри них — прямоугольники поменьше: заголовки, картинки, кнопки, карточки. Верстальщик сначала видит эти прямоугольники, а уже потом пишет код.

Смотри на макет сверху вниз и задавай себе вопрос: «Где кончается одна смысловая часть и начинается другая?» Обычно это видно по фону, по большому заголовку или по отступу.

Отдельно ищи **повторы**. Шесть одинаковых карточек фильмов — это один блок «карточки», внутри которого повторяется одна карточка. Сверстаешь её один раз — и просто скопируешь.

Каждому блоку дай короткое английское имя по смыслу. Эти имена станут классами в CSS. Частые имена: `header` — шапка, `hero` — первый экран, `cards` — карточки, `about` — о нас, `footer` — подвал.

Так выглядит страница, если обвести каждый блок рамкой:

## Делаем свой сайт

<ForCase>
Выберите кейс на главной странице навигатора — здесь появится подсказка, какие блоки обычно есть у вашего сайта.
</ForCase>

<ForCase id="watch">
Обычно на главной: шапка → первый экран с кнопкой «Создать комнату» → «как это работает» → карточки фильмов → подвал. Повтор — карточки фильмов.
</ForCase>

<ForCase id="teammate">
Обычно на главной: шапка → первый экран «Найти команду» → карточки анкет → отзывы → подвал. Повторы — анкеты и отзывы.
</ForCase>

<ForCase id="where">
Обычно на главной: шапка → первый экран → фильтры → карточки событий → подвал. Повторы — кнопки фильтров и карточки событий.
</ForCase>

<ForCase id="tail">
Обычно на главной: шапка → первый экран «Пройти тест» → карточки питомцев → форма «Стать волонтёром» → подвал. Повтор — карточки питомцев.
</ForCase>

<ForCase id="split">
Обычно на главной: шапка → первый экран «Создать сбор» → «как это работает» → пример сбора с прогрессом → подвал. Повтор — шаги «как это работает».
</ForCase>

1. Откройте макет главной страницы вашего кейса в Figma.
2. Пройдите по нему сверху вниз и выпишите крупные блоки. Для каждого — английское имя и что внутри.
3. Отметьте повторы: что на странице похоже друг на друга.
4. Распределите блоки между участниками команды. Каждый потом отвечает за свой кусок.

Запишите список в заметки или прямо на листке. Он понадобится в шаге 1.3.

<Hint title="Подсказка 1">
Не спешите. Сначала найдите самые большие части — обычно у них разный фон. Шапка всегда наверху, подвал — внизу. Всё, что между ними, — секции.
</Hint>

<Hint title="Подсказка 2">
В Figma слева есть панель слоёв (Layers). Дизайнеры часто уже называют там фреймы: Header, Hero, Footer. Кликните по фрейму — на макете подсветится его рамка.
</Hint>

<Hint title="Решение">
Пример для кейса ХВОСТ_ДОМОЙ:

```text
header    — логотип, меню (О нас, Питомцы, Помочь), кнопка «Взять питомца»
hero      — большой заголовок, текст, кнопка, фото собаки
pets      — заголовок «Ищут дом» + 6 карточек питомцев (повтор!)
volunteer — форма «Стать волонтёром»: имя, телефон, кнопка
footer    — контакты, соцсети, адрес
```
</Hint>
