## Теория

<Npc>

Сайт — это просто папка с файлами. В `index.html` лежит содержимое страницы: тексты, картинки, ссылки. В `style.css` — оформление: цвета, размеры, расположение. Картинки кладём в папку `img`.

У любой страницы одинаковый каркас:

```html
<!DOCTYPE html>          <!-- «это современный HTML» -->
<html lang="ru">         <!-- вся страница, язык — русский -->
  <head>                 <!-- служебное, на экране не видно -->
    <meta charset="UTF-8">
    <title>Хвост домой</title>          <!-- название вкладки -->
    <link rel="stylesheet" href="style.css">
  </head>
  <body>                 <!-- всё, что видно на экране -->
    <h1>Найди друга в приюте</h1>
  </body>
</html>
```

`<!DOCTYPE html>` — первая строка: браузер понимает, что перед ним современный HTML. `<html lang="ru">` оборачивает всю страницу. Внутри две части: в `<head>` лежит служебное — кодировка, название вкладки, подключение стилей. В `<body>` — всё, что человек видит на экране: заголовки, текст, картинки, кнопки.

Писать код будем в **VS Code** — это бесплатный редактор. Расширение **Live Server** запускает страницу в браузере и обновляет её после каждого сохранения. Не нужно каждый раз нажимать F5.

Файл стилей подключается к странице одной строкой внутри `<head>`. Без неё браузер не узнает про `style.css`:

```html
<link rel="stylesheet" href="style.css">
```

Лайфхак: в пустом `index.html` набери `!` и нажми Tab. VS Code сам напишет заготовку страницы. Останется поменять `lang="en"` на `lang="ru"` и добавить строку со стилями.

## Делаем свой сайт

Каждый участник делает это у себя на компьютере:

1. Установите [VS Code](https://code.visualstudio.com/) и в нём расширение **Live Server** (вкладка Extensions, Ctrl+Shift+X).
2. Скачайте стартовый шаблон — два файла:
   <a href="../../starter/index.html" download>index.html</a> и
   <a href="../../starter/style.css" download>style.css</a>. Рядом создайте пустую папку `img`.
   Положите всё в одну папку, например `hvost-domoy`.
3. В VS Code: «Файл → Открыть папку» и выберите эту папку.
4. Откройте `index.html` и нажмите **Go Live** внизу справа. Страница откроется в браузере.
5. Поменяйте текст в `<title>` и `<h1>` на название своего проекта, сохраните (Ctrl+S) — браузер обновится сам.

<Hint title="Подсказка 1">
Кнопка **Go Live** появляется в синей полосе внизу окна VS Code, только когда открыта папка, а не один файл.
</Hint>

<Hint title="Подсказка 2">
Если браузер показывает список файлов вместо страницы — значит, Live Server запущен не в той папке. Файл должен называться ровно `index.html`, маленькими буквами.
</Hint>

<Hint title="Решение">
Так выглядит минимальный `index.html` с подключёнными стилями:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>ХВОСТ_ДОМОЙ</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>ХВОСТ_ДОМОЙ</h1>
</body>
</html>
```
</Hint>
