## Теория

<Npc>

Для JavaScript страница — это дерево объектов, **DOM**. Каждый тег — объект, который можно найти и поменять. Ищем так же, как в CSS, селектором: `document.querySelector('.menu')` возвращает первый подходящий элемент. Если ничего не нашлось — `null`.

Менять вид элемента лучше всего **классами**. В CSS заранее описываем, как выглядит `.menu.open`, а в JS только добавляем или убираем класс: `classList.add('open')`, `classList.remove('open')` или `classList.toggle('open')` — «было — убери, не было — добавь».

Реакция на действия пользователя — **события**. `addEventListener('click', функция)` говорит элементу: «когда по тебе кликнут, запусти эту функцию».

```js
const button = document.querySelector('.theme-button');

button.addEventListener('click', function () {
  document.body.classList.toggle('dark');
});
```

Почти весь интерактив на сайтах — это три строки: найти элемент, дождаться события, переключить класс.

## Делаем свой сайт

1. Найдите на своём макете, что должно меняться по клику: кнопка «в избранное», переключатель, вкладки, раскрывающийся ответ.
2. Опишите в CSS, как элемент выглядит в «нажатом» состоянии, через дополнительный класс: `.fav.active`.
3. В `script.js` найдите элемент и переключайте класс по клику.
4. Проверьте в браузере и в консоли: ошибок нет, класс переключается (видно в DevTools → Elements).

<Hint title="Подсказка 1">
Порядок всегда один: сначала `const кнопка = document.querySelector(…)`, потом `кнопка.addEventListener('click', function () { … })`, внутри — `classList.toggle`.
</Hint>

<Hint title="Подсказка 2">
Класс нужно переключать у `document.body`, а не у кнопки: тема меняется у всей страницы.
</Hint>

<Hint title="Решение">
```js
const themeButton = document.querySelector('.theme-button');

themeButton.addEventListener('click', function () {
  document.body.classList.toggle('dark');
});
```
</Hint>
