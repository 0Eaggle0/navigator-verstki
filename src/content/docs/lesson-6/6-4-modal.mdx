## Теория

<Npc>

**Модальное окно** — окно поверх страницы: форма записи, «создать комнату», подробности события. Пока оно открыто, страница за ним затемнена и не нажимается.

Раньше такие окна собирали из `div` и десятка строк JS. Сейчас в HTML есть готовый тег `<dialog>`. Браузер сам рисует его поверх страницы, затемняет фон, закрывает окно по Esc и держит фокус клавиатуры внутри окна.

Открыть и закрыть — две команды:

```js
modal.showModal(); // открыть поверх страницы с затемнением
modal.close();     // закрыть
```

Цвет затемнения задаёт CSS-псевдоэлемент `::backdrop`: `.modal::backdrop { background: rgba(0, 0, 0, 0.5); }`.

<Hint title="Подсказка 1">
Если окно открывают несколько кнопок (в каждой карточке), найдите их все через `document.querySelectorAll('.open-modal')` — он вернёт список. Потом повесьте обработчик на каждую кнопку списка. `forEach` читается как «для каждой кнопки `b` сделай…» (подробнее — в шаге 7.1): `buttons.forEach((b) => b.addEventListener('click', () => modal.showModal()));`.
</Hint>

<Hint title="Подсказка 2">
Форма внутри `<dialog>` с атрибутом `method="dialog"` сама закрывает окно при нажатии на кнопку отправки — даже без JS.
</Hint>

<Hint title="Решение">
```js
const modal = document.querySelector('.modal');
const openButton = document.querySelector('.open-modal');
const closeButton = document.querySelector('.close-modal');

openButton.addEventListener('click', function () {
  modal.showModal();
});

closeButton.addEventListener('click', function () {
  modal.close();
});
```
</Hint>
