## Теория

<Npc>

На телефоне пять пунктов меню в строку не помещаются. Решение — **бургер**: кнопка ☰, по которой меню выезжает или раскрывается. Это соединение двух прошлых тем: медиазапрос прячет меню на узком экране, а JavaScript по клику переключает класс, который его показывает.

Схема такая. В медиазапросе для телефона: `.menu { display: none; }`, `.menu.open { display: flex; }`, а кнопка `.burger` видна. На компьютере наоборот: бургер спрятан, меню стоит в строку, как раньше.

JavaScript почти такой же, как в шаге 6.2: найти кнопку, по клику сделать `menu.classList.toggle('open')`.

Для доступности кнопке нужны `aria-label="Открыть меню"` (что это за кнопка) и `aria-expanded` (открыто меню или нет). `classList.toggle` возвращает `true`, если класс добавился, — это значение удобно сразу записать в атрибут.

```js
const isOpen = menu.classList.toggle('open');
burger.setAttribute('aria-expanded', isOpen);
```

## Делаем свой сайт

1. Добавьте в шапку кнопку `<button class="burger" type="button" aria-expanded="false" aria-label="Открыть меню">☰</button>`.
2. В CSS спрячьте её на компьютере: `.burger { display: none; }`.
3. В медиазапросе для телефона (`max-width: 768px`): верните шапке строку с переносом, покажите бургер, поставьте `nav` отдельной строкой на всю ширину, спрячьте меню и добавьте правило `.menu.open`.
4. В `script.js` переключайте класс `open` и `aria-expanded` по клику.
5. Проверьте на 375 px и на 1280 px.

<Hint title="Подсказка 1">
В занятии 5 шапка на телефоне стала столбиком. С бургером удобнее строка: логотип слева, ☰ справа, а меню — отдельной строкой ниже. Поэтому в медиазапросе снова пишем `.header .container { flex-direction: row; flex-wrap: wrap; }`. Правила бургера добавляйте в самый конец медиазапроса из занятия 5 — тогда они перебьют старые.
</Hint>

<Hint title="Подсказка 2">
`setAttribute('aria-expanded', isOpen)` сам превратит `true` и `false` в строки `"true"` и `"false"`.
</Hint>

<Hint title="Решение">
```js
const burger = document.querySelector('.burger');
const menu = document.querySelector('.menu');

burger.addEventListener('click', function () {
  const isOpen = menu.classList.toggle('open');
  burger.setAttribute('aria-expanded', isOpen);
});
```

```css
.burger {
  display: none;
}

@media (max-width: 768px) {
  /* логотип и ☰ в строку, меню переносится ниже */
  .header .container {
    flex-direction: row;
    flex-wrap: wrap;
  }

  .burger {
    display: block;
  }

  /* меню — отдельной строкой на всю ширину */
  .header nav {
    order: 1;
    width: 100%;
  }

  .menu {
    display: none;
    flex-direction: column;
  }

  .menu.open {
    display: flex;
  }
}
```
