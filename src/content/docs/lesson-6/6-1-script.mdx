## Теория

HTML — это содержимое, CSS — оформление, а **JavaScript** — поведение: реакция на клики, открытие меню, фильтры. Код пишем в отдельном файле `script.js` и подключаем в самом конце `<body>`: `<script src="script.js"></script>`. К этому моменту весь HTML уже загружен, и скрипт может с ним работать.

**Консоль** — окно, куда код пишет сообщения. Откройте F12 → вкладка **Console**. Команда `console.log('привет')` выводит туда текст. Так проверяют, что код вообще запустился и что лежит в переменных. Ошибки тоже появляются там, красным.

**Переменная** — коробка с именем: `const name = 'Аня';`. `const` — значение не меняется, `let` — может меняться: `let count = 0; count = count + 1;`. Строки пишутся в кавычках, числа — без.

**Функция** — кусок кода с именем, который можно запускать много раз. В скобках — параметр, `return` возвращает результат:

```js
function greet(n) {
  return 'Привет, ' + n + '!';
}
console.log(greet('Аня')); // Привет, Аня!
```

## Делаем свой сайт

1. Создайте рядом с `index.html` пустой файл `script.js`.
2. Подключите его в `index.html` последней строкой перед `</body>`: `<script src="script.js"></script>`.
3. Напишите в `script.js` строку `console.log('Скрипт подключён!');`, сохраните и откройте консоль браузера (F12 → Console). Сообщение появилось — всё работает.
4. Договоритесь в команде: JavaScript пишет один человек, остальные присылают ему свои кусочки. Иначе файл сломается от одновременных правок.

<Hint title="Подсказка 1">
Строки можно склеивать плюсом: `'Привет, ' + n + '!'`. Или использовать обратные кавычки: `` `Привет, ${n}!` `` — внутри `${}` подставится значение переменной.
</Hint>

<Hint title="Подсказка 2">
Чтобы записать текст в элемент, найдите его и поменяйте свойство `textContent`: `document.querySelector('h1').textContent = 'новый текст';`.
</Hint>

<Hint title="Решение">
```js
const name = 'Аня';

function greet(n) {
  return 'Привет, ' + n + '!';
}

console.log(greet(name));
document.querySelector('h1').textContent = greet(name);
```
</Hint>
