## Теория

<Npc>

**Адаптив** — это когда один сайт хорошо выглядит и на компьютере, и на телефоне. Основной инструмент — **медиазапрос**: блок CSS, который работает только при нужной ширине экрана.

```css
@media (max-width: 768px) {
  h1 { font-size: 24px; }
}
```

Читается так: «если ширина экрана не больше 768 px, заголовку — 24 px». На широком экране правило внутри просто игнорируется. Медиазапросы ставят в самый конец `style.css`: так они перекрывают обычные правила выше.

Чтобы телефон не притворялся широким экраном, в `<head>` нужна строка `<meta name="viewport" content="width=device-width, initial-scale=1.0">`. В стартовом шаблоне она уже есть.

Проверять адаптив удобно без телефона: F12 → значок телефона слева вверху (или Ctrl+Shift+M). Сверху появится выбор устройства и ширины — поставьте 375 px, это ширина обычного смартфона.

## Делаем свой сайт

1. Проверьте, что в `<head>` вашего `index.html` есть meta viewport.
2. Откройте сайт, включите режим устройства в DevTools и поставьте ширину 375 px.
3. Пролистайте страницу сверху вниз и запишите, что сломалось: где горизонтальная прокрутка, что вылезает, что слишком мелко или крупно.
4. Добавьте в конец `style.css` пустой медиазапрос `@media (max-width: 768px) { }` — в следующем шаге будем его наполнять.

<Hint title="Подсказка 1">
В режиме устройства удобно выбрать **Dimensions: Responsive** и тянуть край страницы мышкой — видно, на какой ширине вёрстка начинает ломаться.
</Hint>

<Hint title="Подсказка 2">
Горизонтальную прокрутку обычно дают: картинки без `max-width: 100%`, фиксированные `width` в px больше 375, сетки с тремя колонками по 300 px.
</Hint>

<Hint title="Решение">
```css
@media (max-width: 768px) {
  h1 {
    font-size: 24px;
  }

  .row {
    flex-direction: column;
  }
}
```
</Hint>
