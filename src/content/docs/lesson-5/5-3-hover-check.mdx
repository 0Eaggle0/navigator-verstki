## Теория

<Npc>

Кнопка, которая не реагирует на мышку, кажется «мёртвой». Псевдокласс `:hover` задаёт стили на время наведения: `.button:hover { background: #E85A24; }`. Чаще всего меняют цвет фона, подчёркивание ссылки или слегка поднимают карточку.

Чтобы смена была плавной, обычному правилу добавляют `transition: 0.2s` — браузер сам нарисует промежуточные кадры. Писать `transition` нужно именно в обычное правило, не в `:hover`.

Для тех, кто ходит по сайту клавиатурой (Tab), есть похожий `:focus-visible`. Удобно писать их вместе: `.button:hover, .button:focus-visible { … }`.

**Сверка с макетом** — финальный проход. Поставьте макет и страницу рядом на одинаковой ширине и идите сверху вниз: шрифты, цвета, отступы, выравнивание. Правьте то, что заметно с первого взгляда, а не каждый пиксель.

## Делаем свой сайт

1. Добавьте `:hover` всем кнопкам, пунктам меню и карточкам. Состояния наведения часто нарисованы в макете отдельно — поищите.
2. Добавьте `transition` к этим элементам.
3. Сверьте страницу с макетом на 1280 px и на 375 px. Составьте список отличий и исправьте главные.
4. Пройдите чек-лист ниже — если всё отмечено, **минимум проекта выполнен**. 🎉

<TeamTasks />

<Hint title="Подсказка 1">
Если в макете нет отдельного состояния наведения, сделайте цвет кнопки чуть темнее. Хватит разницы в 10–15% яркости.
</Hint>

<Hint title="Подсказка 2">
Карточки красиво «приподнимаются»: `transform: translateY(-4px); box-shadow: 0 8px 24px rgba(0, 0, 0, 0.1);` при наведении и `transition: 0.2s` в обычном правиле.
</Hint>

<Hint title="Решение">
```css
.button {
  transition: 0.2s;
}

.button:hover,
.button:focus-visible {
  background: #E85A24;
}

.menu a:hover {
  color: var(--color-accent);
}

.card {
  transition: 0.2s;
}

.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.1);
}
```
</Hint>
