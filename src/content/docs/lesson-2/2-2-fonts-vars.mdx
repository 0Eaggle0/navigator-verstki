## Теория

<Npc>

**Шрифт** из макета подключаем с [Google Fonts](https://fonts.google.com/): находим шрифт, выбираем начертания (например, 400 и 700), жмём **Get embed code** и копируем строки `<link>` в `<head>` — выше строки со `style.css`. Потом пишем в CSS `font-family: 'Montserrat', sans-serif;`. Слово `sans-serif` — запасной шрифт на случай, если основной не загрузился.

**CSS-переменная** — это имя для значения. Цвет `#FF6B35` встречается в макете 10 раз? Записываем его один раз в `:root` и дальше пишем `var(--accent)`. Захотели поменять акцент — меняем одну строку.

```css
:root {
  --accent: #FF6B35;
  --text: #1E1E1E;
}
.button { background: var(--accent); }
```

**Сброс стилей.** У браузера есть свои стили: отступы у `body`, `h1`, `p`, точки у списков. Из-за них вёрстка не совпадает с макетом. Сброс убирает их в начале `style.css`. В стартовом шаблоне он уже есть — посмотрите, что там написано.

## Делаем свой сайт

1. Найдите шрифты из паспорта стиля на Google Fonts и вставьте строки `<link>` в `<head>` своего `index.html`.
2. В `style.css` в блоке `:root` запишите цвета из паспорта стиля переменными. В стартовом шаблоне уже есть заготовки `--color-text`, `--color-accent`.
3. Замените `--font-main` на свой шрифт.
4. Проверьте в браузере: текст сменил шрифт, фон и цвет текста как в макете.

<TeamTasks />

<Hint title="Подсказка 1">
На Google Fonts: откройте шрифт → **Get font** → **Get embed code**. Справа будут два блока: `<link>` для HTML и `font-family` для CSS. Копируйте оба.
</Hint>

<Hint title="Подсказка 2">
Имена переменных придумывайте по роли, а не по цвету: `--accent`, `--bg`, `--text-muted`. Имя `--orange` станет враньём, если дизайнер поменяет цвет на синий.
</Hint>

<Hint title="Решение">
В `<head>`:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Montserrat:wght@400;700&display=swap" rel="stylesheet">
<link rel="stylesheet" href="style.css">
```

В `style.css`:

```css
:root {
  --color-bg: #FFF8F0;
  --color-text: #1E1E1E;
  --color-accent: #FF6B35;
  --color-muted: #6B6B6B;
  --font-main: 'Montserrat', sans-serif;
}

body {
  font-family: var(--font-main);
  color: var(--color-text);
  background: var(--color-bg);
}
```
</Hint>
