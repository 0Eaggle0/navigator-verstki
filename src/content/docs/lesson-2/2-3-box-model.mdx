## Теория

Каждый элемент на странице — прямоугольник из четырёх слоёв: **контент** → **padding** (внутренний отступ) → **border** (рамка) → **margin** (внешний отступ до соседей). Это и есть блочная модель.

По умолчанию `width` задаёт ширину только контента, а padding и рамка прибавляются сверху: `width: 200px` + `padding: 16px` превращается в 234 px. Строка `box-sizing: border-box` меняет правило: `width` — это ширина вместе с padding и рамкой. С ней считать проще, поэтому её ставят всем элементам в сбросе.

Отступы пишутся одной строкой по часовой стрелке от верха: `padding: 16px 24px` — сверху и снизу 16, слева и справа 24.

**Контейнер** — обёртка, которая не даёт контенту растянуться на весь широкий экран. Ширина из макета (например, 1200 px) записывается в `max-width`, а `margin: 0 auto` ставит контейнер по центру. На узком экране `max-width` не мешает: контейнер просто сужается.

## Делаем свой сайт

1. Внутри каждой секции оберните содержимое в `<div class="container">`. Секция даёт фон на всю ширину, а контейнер держит контент по центру. **В шапке и подвале — тоже:** `<header class="header"><div class="container">логотип, меню, кнопка</div></header>`.
2. Задайте `.container` ширину контейнера из паспорта стиля и `margin: 0 auto`. Добавьте боковые отступы `padding: 0 16px`, чтобы на телефоне текст не прилипал к краю.
3. Задайте секциям вертикальные отступы из макета: `padding: 80px 0`.
4. Откройте DevTools (F12) и сравните отступы с Figma.

<Hint title="Подсказка 1">
Контейнер один раз описывается в CSS, а в HTML используется в каждой секции:
`<section class="pets"><div class="container">…</div></section>`.
</Hint>

<Hint title="Подсказка 2">
Если в макете между секциями 80 px, а у вас больше, проверьте margin у заголовков и абзацев внутри. Сброс убирает их отступы, поэтому задавайте их явно.
</Hint>

<Hint title="Решение">
```css
.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 16px;
}

section {
  padding: 80px 0;
}

h2 {
  margin-bottom: 32px;
}
```

```html
<header class="header">
  <div class="container">
    <a class="logo" href="#">ХВОСТ_ДОМОЙ</a>
    <nav>
      <ul class="menu">…</ul>
    </nav>
    <a class="button" href="#pets">Взять питомца</a>
  </div>
</header>

<main>
  <section class="pets" id="pets">
    <div class="container">
      <h2>Ищут дом</h2>
      <!-- карточки -->
    </div>
  </section>
</main>

<footer class="footer">
  <div class="container">
    <!-- контакты -->
  </div>
</footer>
```
