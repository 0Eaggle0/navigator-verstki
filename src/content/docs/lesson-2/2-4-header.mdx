## Теория

<Npc>

Шапка — первое, что видит человек. Её оформляем первой: на ней проверяем, что шрифты и цвета подключены правильно. Располагать элементы в строку будем в занятии 3 через Flexbox, сейчас — только внешний вид.

Ссылки браузер подчёркивает и красит в синий. Для меню это обычно не нужно: `text-decoration: none` убирает линию, `color` задаёт свой цвет.

Кнопка-ссылка — это `<a>` с фоном и отступами. Ссылка по умолчанию **строчная**: вертикальные отступы у неё работают странно. Поэтому кнопкам пишут `display: inline-block` — и отступы, и ширина начинают работать как у блока.

Скруглённые углы задаёт `border-radius`: `8px` — слегка скруглённые, `999px` — «таблетка».

## Делаем свой сайт

1. Задайте шапке фон и внутренние отступы из макета.
2. Оформите логотип: размер, начертание, цвет. Если логотип — картинка, задайте ей высоту.
3. Уберите подчёркивание у пунктов меню, задайте цвет и размер шрифта.
4. Оформите класс `.button`: фон, цвет текста, отступы, скругление. Это общий стиль для всех кнопок-ссылок — в шапке, на первом экране, в карточках. Оформите один раз, и все кнопки станут кнопками.

Шапка может пока стоять «столбиком» — в строку её поставим на следующем занятии.

<Hint title="Подсказка 1">
Пишите стили по классам, которые уже стоят в вашем HTML. Нет класса — добавьте его: `<a class="logo" href="#">`. Стили для тегов вроде `a { … }` поменяют все ссылки на странице сразу.
</Hint>

<Hint title="Подсказка 2">
Цвета берите из переменных: `background: var(--color-accent)`. Если нужного цвета нет в `:root`, добавьте туда новую переменную.
</Hint>

<Hint title="Решение">
```css
.header {
  padding: 16px 0;
  background: #FFFFFF;
}

.logo {
  font-size: 24px;
  font-weight: 700;
  color: var(--color-accent);
  text-decoration: none;
}

/* промежутки между пунктами зададим в 3.2 через gap */
.menu a {
  color: var(--color-text);
  text-decoration: none;
}

.button {
  display: inline-block;
  padding: 10px 20px;
  border-radius: 999px;
  background: var(--color-accent);
  color: #FFFFFF;
  font-weight: 600;
  text-decoration: none;
}
```
</Hint>
