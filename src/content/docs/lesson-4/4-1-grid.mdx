## Теория

Flexbox думает рядами: элементы идут друг за другом в строку. **Grid** думает сеткой: сначала рисуем колонки, потом элементы сами раскладываются по ячейкам. Поэтому сетку карточек удобнее делать на Grid — все колонки ровные, даже на последней неполной строке.

Сетка включается у родителя: `display: grid`. Колонки задаёт `grid-template-columns`: `200px 200px 200px` — три колонки по 200 px. Но чаще пишут `1fr 1fr 1fr`: **fr** — доля свободного места, три равные колонки на любую ширину.

Чтобы не повторяться, есть `repeat`: `repeat(3, 1fr)` = `1fr 1fr 1fr`. Промежутки между ячейками, как и во флексе, задаёт `gap`.

## Делаем свой сайт

1. Пройдите [Grid Garden](https://cssgridgarden.com/#ru) до 10-го уровня (10 минут).
2. Найдите на макете всё, что выглядит как сетка: карточки, галерея, колонки в футере. Посчитайте, сколько там колонок и какие промежутки.
3. Запишите это рядом с паспортом стиля — пригодится в следующих двух шагах.

<Hint title="Подсказка 1">
Колонок в сетке столько, сколько значений в `grid-template-columns`: `1fr 1fr` — две, `repeat(4, 1fr)` — четыре.
</Hint>

<Hint title="Подсказка 2">
В DevTools рядом с элементом с `display: grid` есть значок **grid**. Нажмите — на странице нарисуются линии сетки с номерами.
</Hint>

<Hint title="Решение">
```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}
```
</Hint>
