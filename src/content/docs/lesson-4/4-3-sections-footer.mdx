## Теория

Все инструменты уже у вас в руках: семантика, стили, Flexbox, Grid. Остальные секции — это комбинации того же. Посмотрите на секцию и спросите: это **ряд** (Flexbox) или **сетка** (Grid)? «Как это работает» из трёх шагов — сетка из трёх колонок. Отзывы — тоже сетка. Форма — столбик полей.

**Подвал** обычно состоит из колонок: логотип с описанием, ссылки, контакты. Это Grid на 3–4 колонки. Под колонками часто есть строка копирайта — она просто идёт следующим блоком.

Тёмный подвал — частый приём. На тёмном фоне текст делают светлым, а второстепенный — полупрозрачным: `color: rgba(255, 255, 255, 0.7)`.

Проверяйте себя сравнением: откройте макет и свою страницу рядом на одном экране, ширину окна поставьте как у макета.

1. Пройдите макет сверху вниз и отметьте секции, которые ещё не оформлены.
2. Распределите их между участниками. Каждый оформляет свою секцию, модератор собирает CSS в один файл.
3. Для каждой секции решите: ряд или сетка? Сделайте раскладку, потом оформление.
4. Сверстайте подвал сеткой из колонок.
5. Откройте страницу на ширине 1280 px рядом с макетом и поправьте заметные отличия.

<Hint title="Подсказка 1">
Чтобы CSS разных участников не мешал друг другу, каждый пишет стили только со своим классом секции в начале: `.steps h3`, `.steps .icon`. Тогда блоки собираются в один файл без конфликтов. Работать удобно в шаблоне <a href="../../starter/section.html" download>section.html</a> + <a href="../../starter/section.css" download>section.css</a>: он подключает общий `style.css`.
</Hint>

<Hint title="Подсказка 2">
Строку копирайта под колонками сделайте отдельным блоком с верхней линией: `border-top: 1px solid rgba(255, 255, 255, 0.2); margin-top: 24px; padding-top: 16px;`.
</Hint>

<Hint title="Решение">
```css
.footer {
  padding: 48px 0 24px;
  background: #1E1E1E;
  color: #FFFFFF;
}

.footer__cols {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}

.footer__copy {
  margin-top: 24px;
  padding-top: 16px;
  border-top: 1px solid rgba(255, 255, 255, 0.2);
  color: rgba(255, 255, 255, 0.7);
}

/* «Как это работает»: три шага в ряд */
.steps__list {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}
```
