## Теория

В шаге 4.1 колонок было ровно три. Но на телефоне три колонки не поместятся. Есть запись, при которой сетка сама решает, сколько колонок влезает:

```css
grid-template-columns: repeat(auto-fill, minmax(240px, 1fr));
```

Читается так: «сделай столько колонок, сколько влезет (`auto-fill`), каждая не уже 240 px и не шире доли свободного места (`minmax(240px, 1fr)`)». На компьютере получится 3–4 колонки, на телефоне — одна. И без единого медиазапроса.

Картинки в карточках обычно разного размера. Чтобы все были одинаковыми, им задают размер (`height` или `aspect-ratio: 3 / 2`), а `object-fit: cover` обрезает лишнее без сплющивания — как фото в рамке.

Сама карточка внутри — флекс-столбик: картинка, заголовок, текст, кнопка. `margin-top: auto` у кнопки прижимает её к низу, и кнопки во всех карточках стоят на одной линии.

## Делаем свой сайт

1. Проверьте HTML: все карточки лежат в одном контейнере (`.cards`), каждая — `article` с одинаковой разметкой.
2. Поставьте их в сетку через `repeat(auto-fill, minmax(…, 1fr))`. Минимальную ширину подберите так, чтобы на компьютере колонок было столько же, сколько в макете.
3. Оформите одну карточку по макету, остальные подтянутся сами.
4. Сузьте окно браузера — сетка должна перестраиваться без горизонтальной прокрутки.

<Hint title="Подсказка 1">
Как подобрать minmax: ширина контейнера 1200 px, промежутки 24 px, в макете 3 колонки → (1200 − 2 × 24) / 3 ≈ 384. Минимум возьмите чуть меньше, например 300 px.
</Hint>

<Hint title="Подсказка 2">
Если нужно ровно N колонок на компьютере, можно написать `repeat(3, 1fr)`, а перестройку для телефона сделать в занятии 5 медиазапросом. Оба способа нормальные.
</Hint>

<Hint title="Решение">
```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
  gap: 24px;
}

.card {
  display: flex;
  flex-direction: column;
  gap: 8px;
  padding: 16px;
  border-radius: 16px;
  background: var(--color-bg-card, #FFF5EC);
}

.card img {
  width: 100%;
  aspect-ratio: 3 / 2;
  object-fit: cover;
  border-radius: 12px;
}

.card .button {
  margin-top: auto;
}
```
</Hint>
