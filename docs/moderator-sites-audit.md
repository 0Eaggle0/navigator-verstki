# Итоговая проверка готовых сайтов

Дата: 12 ноября 2026 года. Проверено состояние кода `5bf8aeb` после этапов 1–7.

Этап 8 завершён: в перечисленных ниже сценариях новых ошибок не обнаружено, изменений кода не потребовалось. Проверка выполнена в Chromium через Playwright, в отдельном браузерном профиле. Пользовательские данные не изменялись.

Дополнительно проверены переходы по 48 уникальным внутри каждого примера hash-ссылкам: ошибок JavaScript не зарегистрировано, картинки загружаются. Это проверка навигации по существующим ссылкам, а не подтверждение полноты относительно всех макетов.

Для каждого из пяти сайтов искусственно вызвана ошибка записи в localStorage: сообщение об ошибке видно, введённый текст остаётся в форме, ложного сохранения нет.

Архивы скачаны кнопками страницы модератора, распакованы и проверены. Списки файлов и содержимое совпадают с исходниками; CRC32 каждой записи корректна. При сравнении текстовых исходников учитывалась нормализация CRLF/LF сборщиком.

Все пять распакованных `index.html` открыты через `file://` при заблокированных HTTP/HTTPS-запросах. Локальные картинки и стили доступны, ошибок JavaScript нет. Проверены пробные действия: закладка фильма, разделение чека, отметка «Иду», сохранение и восстановление профиля TeamPlay, подбор питомца.

Для ZIP «Хвоста» смоделирован HTTP 404 картинки: показана ошибка, кнопка снова доступна. После восстановления загрузки повторное скачивание успешно.

## Сборка и доступ модератора

- `npm run build` завершилась успешно: 57 страниц, обе страницы модератора зашифрованы. В исходном HTML страницы готовых сайтов отсутствуют открытые `nav-site` и `data-sources`.
- Отдельная сборка с `BASE_PATH=/audit/`, тестовым `SITE` и временным тестовым кодом доступа также прошла. Рабочий `.env` и основная папка `dist` для неё не менялись: использован `--outDir .astro/audit/production`.
- В браузере на отдельной сборке неверный код отклонён, верный открыл пять превью. После перезагрузки доступ восстановился. Пути картинок содержат `/audit/`; ZIP TeamPlay скачан успешно.
- В локальной основной сборке без `SITE` ожидаемо пропускается sitemap. В отдельной сборке с `SITE` sitemap создан.

Логи и распакованные архивы проверки находятся в игнорируемой папке `.astro/audit/`; лог основной сборки — `.astro/final-audit-build.log`. Они не включены в репозиторий.

## Границы результата

- Это учебные локальные реализации. Нет серверных аккаунтов, обмена между устройствами, настоящих платежей, синхронного просмотра кино и отправки заявок организаторам.
- Полная сверка Киносферы с Figma остаётся незавершённой: на предыдущем этапе макет возвращал HTTP 403. Для завершения нужен доступный макет или его экспорт. У «Хвоста» отдельный макет не предоставлен.
- Превью поддерживает `index.html` и hash-разделы. Для будущих отдельных HTML-страниц понадобится расширить загрузчик; текущие примеры используют hash-навигацию.
- Внешние шрифты и ссылки требуют сети; офлайн проверялось использование локальных ресурсов и системных шрифтов.
- Firefox, Safari, реальные мобильные устройства и опубликованный GitHub Pages в этом этапе не проверялись. Локально проверены основная сборка и сборка в подпапке.
