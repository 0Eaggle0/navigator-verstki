## Исправление, найденное на финальном прогоне

Правильные решения иногда отклонялись при проверке сразу после перехода: `checkVisibility()` видел невидимые элементы, а вычисленные колонки и медиазапросы соответствовали ещё не завершённой раскладке iframe. Ошибка воспроизведена в отдельной фазе `layout` на неизменённой сборке. Принудительный расчёт геометрии родительского iframe перед присвоением `srcdoc` дал 60 успешных проверок. Исправление внесено в `src/lib/check-frame.ts`; затем повторены все фазы на новой сборке, включая 60 проверок без диагностической подмены.

В новом тесте модератора исправлено неверное ожидание: `nav-team` — временный ключ; компонент журнала переносит имена в `nav-attendance` и удаляет его. Тест проверяет имя в журнале после перезагрузки.

Один прогон прервался на тайм-ауте загрузки локального сервера до начала проверок. Повторный полный прогон после завершения сборок прошёл; тайм-аут не засчитан как успешная проверка.

## Повторение

Нужны Chrome и Playwright. Если Playwright находится вне проекта, задайте `NAV_AUDIT_PLAYWRIGHT` как полный путь к его `index.mjs`.

Команды PowerShell для изолированной проверочной сборки (тестовый код публичный, не использовать его для публикации):

```powershell
$env:MODERATOR_CODES = 'audit-only-7: AuditMemberSeven'
$env:BASE_PATH = '/navigator'
npm run build -- --outDir .astro/final-prefix
$env:NAV_AUDIT_DIST = '.astro/final-prefix'
$env:NAV_AUDIT_PREFIX = '/navigator'
foreach ($phase in @('layout','practice','edges','games','behavior','block-library','practice-content','check-button','check-storage','legacy','profile','assemble','moderator')) {
  node tools/audit-learning.mjs $phase --verify
  if ($LASTEXITCODE -ne 0) { throw "Проверка $phase не прошла" }
}
$env:NAV_KITS_DIR = '.astro/audit-learning/assembled'
node tools/check-site-kits.mjs
```

Обычная сборка и регистрация:

```powershell
Remove-Item Env:BASE_PATH -ErrorAction SilentlyContinue
npm run build -- --outDir .astro/final-root
$env:NAV_AUDIT_DIST = '.astro/final-root'
Remove-Item Env:NAV_AUDIT_PREFIX -ErrorAction SilentlyContinue
node tools/audit-learning.mjs registration
```

JSON-результаты и журналы лежат в `.astro/audit-learning/`; собранные сайты и снимки — в `.astro/audit-learning/assembled/`. Эти генерируемые файлы не включаются в git. Без `NAV_KITS_DIR` проверка комплектов продолжает собирать их из исходников, как раньше.

## Границы проверки

- Это проверка заданных сценариев, а не доказательство отклонения любого возможного неверного кода. Клиентские зачёты и закрытые блоки можно обойти через DevTools; серверной защиты не добавлено.
- Firefox, Safari, реальные телефоны, скринридер и работа класса в течение целого занятия не проверялись. Проверка клавиатуры не заменяет полный аудит доступности.
- Вход проверялся с отдельным тестовым кодом, без чтения настоящих кодов из `.env`. Развёртывание и внешние таблицы не проверялись.
- Сборка сохраняет предупреждения Vite о `use astro:head-inject`; sitemap пропущен без `SITE`. Обе сборки и Pagefind завершились успешно.
- Индекс codebase-memory не подтвердил актуальность затронутых путей; выводы о реализации основаны на прямом чтении исходников и браузерных проверках.
